# Clovercut 0.1.9

Desktop release for Linux x86_64/ARM64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon.

## Linux packages and installation

- Add native `.deb` and `.rpm` packages for x86_64 and ARM64, alongside the existing AppImages.
- Add a Linux installer that selects an available native package for the distribution and falls back to the portable AppImage. Downloads are checked against the release checksums before installation.
- Honour explicit version and installation-directory overrides through the verified AppImage, and preserve an existing installation if a download fails verification.
- Include the new Linux formats in the updater manifest and release checksums.
- Prepare `clovercut-bin` AUR packaging from the extracted AppImage, including icons and without a runtime FUSE dependency. Automated AUR publication requires the maintainer's SSH key to be configured.

## Desktop editing

- Add a quick-split button beside the timeline playhead, using Clovercut's existing cut command and preserving selection, track targeting, locked tracks and undo.
- Reuse the translated tooltip and keyboard-operable button controls. Hide the button while panning with the hand tool and on touch layouts.

## Documentation

- Refocus the README on Clovercut's desktop workflow and its additions to Concat.
- Move detailed Linux installation and packaging instructions to a dedicated guide.

All features from 0.1.8 remain included. Mobile packages are not part of this release.

## Known macOS compatibility issue

The published macOS packages declare macOS 12, but include Homebrew libraries
built for newer systems. A crash at launch on Monterey 12.7.6 is tracked in
[issue #2](https://github.com/tulcoturo/clovercut/issues/2). A source-built media
runtime targeting macOS 12 is being validated for a subsequent release; it is
not included in the existing 0.1.9 downloads.
