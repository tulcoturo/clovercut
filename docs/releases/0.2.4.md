# Clovercut 0.2.4

## Effects that follow people and faces

- **Subject Neon** and **Subject Electric** add animated light around an analysed person's silhouette while retaining the background.
- **Face Sunglasses** follows detected eyes. **Dog Face** adds ears, muzzle and nose following detected facial landmarks. Up to four faces are supported.
- The bundled facial detector works locally without a model download. Analysed source-time landmarks are cached and reused by preview and export. Accessories disappear when no face is detected.
- Dedicated Subject and Face catalogue categories, animated reference previews and bundled fallback thumbnails for all four effects.
- Source-aware effects apply to video/image clips and run before ordinary image distortions. Crop, mirror and stabilization retain source alignment. Existing background-removal masks and deep-colour sources are preserved.
- Facial accessories are 2D effects following position, size and tilt. This release does not provide a 3D face mesh or expression-triggered filters. Subject analysis retains the existing 10 Hz grid; facial detections use a 20 Hz grid with bounded interpolation, so very fast motion can still limit tracking quality.
- Windows D3D12 software-adapter checks include non-empty facial landmarks and a live-device check after each effect. Facial shaders use fixed calls to avoid the loop/indexing pattern that lost WARP's device during development.

## Editing and preview fixes

- Media-bin Ctrl/Command+A and Delete use the shared keymap while the bin owns focus. Shift ranges and additive selection follow the visible sort order; sorted marquee selection uses stable media IDs.
- Long titles, captions, speech and voiceover text retain caret visibility and scrolling. Title inspector height can be resized; Unicode selection and recording guards remain intact.
- Relink dialogs dismiss through their header close button and outside click.
- Export reporting includes written bytes and final progress without holding job locks during inspection.
- Delivered preview cadence is reported separately from target FPS. Recent-project hover/busy actions, compact new-project scrolling and unchanged UI model publication are more reliable.

## Desktop and compatibility

- Windows and macOS request that the system stay awake while an export or other long host job runs, releasing the request when the final job ends. The display can still turn off. Linux idle/sleep behavior is unchanged.
- Fourteen looks have descriptive display labels, including Instant Print and Point and Shoot. Their saved IDs, shaders and parameter values remain compatible with existing projects.
- The new upstream Concat commits through `9fcd218b` were reviewed and selectively adapted; Clovercut's project compatibility, audio buses and exact retiming remain intact.

## Downloads

Desktop packages cover Linux x86_64/ARM64 (AppImage, deb, rpm), Windows x64/ARM64 (installer and portable ZIP), and macOS Apple Silicon/Intel (DMG). Verify downloads with SHA256SUMS; the updater uses the accompanying manifest.

macOS packages remain ad-hoc signed and are not Apple-notarized. Follow the [first-launch instructions](https://github.com/tulcoturo/clovercut/blob/v0.2.4/docs/MACOS_INSTALLATION.md). Physical Monterey compatibility and preview performance on the reported low-end Windows laptop remain pending hardware feedback. Mobile packages are outside this desktop release.
