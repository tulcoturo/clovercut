# Clovercut 0.2.0

Desktop release for Linux x86_64/ARM64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon.

## macOS compatibility

- Fix the missing `VTPixelRotationSessionCreate` symbol that prevented 0.1.9 from launching on Monterey. Build FFmpeg and its codec dependencies from pinned sources targeting macOS 12, and enforce that minimum across launch dependencies.
- Retain VideoToolbox decoding/encoding, export codecs, alpha output and Rubber Band audio retiming. Remove the unused FFmpeg filter that requires newer VideoToolbox rotation APIs.
- Candidate packages passed native codec and application smoke checks on modern Intel and Apple Silicon macOS runners. Actual launch on Monterey remains unconfirmed because no macOS 12 test machine is available. Intel ONNX features retain their separately guarded runtime minimum.

## Safer projects and background work

- Preserve generated project media when clearing preview caches. Users of 0.1.9 should upgrade before using **Clear project cache**.
- Preserve distinct Unix paths in recent projects, including case differences and literal backslashes.
- Search for missing media in the background with cancellation, deterministic results and protection against directory cycles and broken links.
- Reject obsolete project, timeline and request results from file pickers, captions, speech, stickers and media previews. Older completions cannot consume newer job state or apply to the wrong timeline.
- Preserve distinct equal-sized audio recordings when adopting generated media.

## Editing and desktop polish

- Make the split button beside the playhead optional in **Settings > General**, off by default. The preference is saved, and its label is translated in all 25 locales.
- Add scrolling timeline tabs from upstream while retaining Clovercut's add-timeline control.
- Improve shared icon accessibility and translated recovery/cache feedback.
- Improve Linux installation fallback when AUR packages lag behind the release, and identify another launcher earlier in `PATH`.

## Validation and packages

- Strengthen export checks for codecs, bit depth, colour range, exact frame rate and final-frame content. Seek timeouts no longer count as successful seeks.
- Execute twelve selected desktop regressions in isolated virtual display/audio sessions, alongside workspace lint/tests, documentation checks and connector/gRPC regressions. Physical audio, accessibility and long-duration playback remain separate qualification tasks.
- Continue shipping AppImage, `.deb` and `.rpm` packages on both Linux architectures, Windows installers/portable ZIPs and macOS DMGs, with updater metadata and release checksums.

All features from 0.1.9 remain included. Mobile packages are not part of this release.
