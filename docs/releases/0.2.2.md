# Clovercut 0.2.2

This desktop release improves project browsing and makes export progress and cancellation more reliable. Available for Linux x86_64/ARM64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon.

## Project browsing

- Keep search and Latest/Name sorting available even with only one recent project. Sorting is also available in narrow desktop windows, addressing [issue #10](https://github.com/tulcoturo/clovercut/issues/10).
- Use compact grid/list icons with translated tooltips and accessible actions. Remember the chosen view across restarts.
- Add space below the view selector and above pagination, and clarify empty-library and no-results states.
- Clear search with Escape or the keyboard-accessible clear button, with focus returned to the search input.
- Improve accessible names/actions on home controls and header actions; disabled home cards refuse activation.

## More reliable exports

- Reopening the export panel preserves a running export's progress and status.
- Repeated start/retry/overwrite requests cannot reset an active render.
- Ignore delayed progress, results and publication callbacks from cancelled or replaced exports.
- Cancel the specific job initiated by the panel, protecting another export that may have subsequently acquired the engine slot.

## Performance and validation

Owned-audio comparisons now use bounded 64 KiB buffers, reducing comparison overhead for repeated library use. The measured file-scan improvement is not a general preview or export speed claim.

Validation now includes actual home-screen keyboard/accessibility interactions and a native controller journey covering import, editing, save/reopen, relinking, cancellation and restart of a real export, with independent inspection of the encoded output. Runtime probes record resource cycles and timings; they do not establish a performance budget or physical-device compatibility.

## Packages and macOS first launch

Linux AppImage, `.deb` and `.rpm` packages, Windows installers/portable ZIPs and macOS DMGs are accompanied by updater metadata and checksums. Mobile and Microsoft Store/MSIX packages are not included.

**macOS packages are ad-hoc signed and not Apple-notarized.** Gatekeeper may block first launch. See [macOS installation instructions](https://github.com/tulcoturo/clovercut/blob/main/docs/MACOS_INSTALLATION.md) and [issue #9](https://github.com/tulcoturo/clovercut/issues/9). This release makes that status explicit; it does not resolve notarization without Apple credentials.

The macOS 12-targeted media dependencies remain included. Maintainer validation on a physical Monterey machine remains unavailable; Intel ONNX features retain their separately guarded runtime minimum.
