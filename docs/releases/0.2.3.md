# Clovercut 0.2.3

## Creative effects and animated previews

- Nine new visual effects: Camera Shake, Digital Glitch, VHS Tape, CRT Scanlines,
  Old Film, Kaleidoscope, Tilt Shift, Light Leak and Neon Edges. Their controls
  support keyframes, and Amount zero restores the original picture.
- Hover effect and filter thumbnails to see the actual shader animate or show a
  smooth before/after comparison. Previews are cancellable and cached; software
  adapters retain still thumbnails. Existing transition previews remain available.

## Preview and editing responsiveness

- Faster approximate scrubbing while dragging, followed by exact refinement when
  the pointer rests. Playback and export retain exact timing.
- Device-lost notifications now reach texture-only previews and sibling workers;
  failed headless device replacement is throttled rather than retried every frame.
- Autosave updates saved status without rebuilding the inspector. Unchanged
  dropdowns/dialogs retain their models instead of closing or resetting.
- Progressive edge scrolling, bounded space after the cut, and a larger horizontal
  scrollbar with wheel support. Group drags over a selected transition wash keep
  the clip selection.
- CPU kernels load before voice detection, addressing a Windows/Linux captions
  startup abort with dynamically loaded ggml backends.

## Desktop improvements

- Remember workspace panels, named layout preset, window size and maximization;
  the behavior can be disabled and Reset retains its existing semantics.
- Named playhead colours plus a custom picker; legacy custom colours remain valid.
- Remove missing media with Undo and stale-search protection.
- Enhance displays visual progress and retains existing 4K processing support.
- Thirteen additional language text presets use bundled fonts, with coverage
  checks. Existing per-word styling, vertical text and caption groups are retained.
- macOS safe start draws the window on the CPU while video remains on Metal.
  Confirmations follow platform button order. Checked time arithmetic safely
  handles extreme inputs; AAC mix tails respect the requested sample length.

## Downloads and qualification

Desktop packages cover Linux x86_64/ARM64 (AppImage, deb, rpm), Windows x64/ARM64
(installer and portable ZIP), and macOS Apple Silicon/Intel (DMG). Verify downloads
with SHA256SUMS; the updater uses the accompanying manifest.

macOS packages without Developer ID credentials are ad-hoc signed and not
notarized; follow the [first-launch instructions](../MACOS_INSTALLATION.md).
Hosted-runner checks do not establish physical Monterey compatibility or fix
performance on every Windows laptop. In particular, the low-end Windows preview
report remains open pending measurement on the affected hardware. Mobile builds
are outside this desktop release.
