# Clovercut 0.2.1

This desktop release improves project organisation and turns saved templates into a usable library. Available for Linux x86_64/ARM64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon.

## Projects at scale

- Switch between grid and compact-list layouts on the desktop home screen.
- Browse 24 projects per page. Search and sorting apply to the whole history before pagination, and thumbnails are queued for the visible page.
- Keep more than 40 recent projects without older entries being evicted. Previously evicted projects can be added again by opening their folders.
- Rename a project by clicking its title in the desktop top bar. Enter saves; Escape or leaving the field cancels. The folder and media paths stay unchanged, and the recent-project entry updates after a successful save.

## Saved template management

- Browse saved templates in the editor’s Templates library, with posters, output settings and placeholder counts.
- Edit an independent project copy, update a selected template from the current project, or delete a bundle with confirmation.
- Stage template writes and atomically replace the manifest, preserving the existing template if saving fails. Coordinate readers and writers with a library lock and reclaim obsolete asset generations after successful updates.
- Keep copied projects and their bundled assets usable after the original template is deleted.

See [project and template management](https://github.com/tulcoturo/clovercut/blob/main/docs/PROJECT_LIBRARY.md) for the workflow. These changes address [issue #4](https://github.com/tulcoturo/clovercut/issues/4). Interface labels are translated in all 25 locales.

## Packages and compatibility

All 0.2.0 fixes remain included, including the macOS 12-targeted media dependencies and safer cache cleanup. Actual launch on Monterey remains unconfirmed because no macOS 12 test machine is available; Intel ONNX features retain their separately guarded runtime minimum.

Linux AppImage, `.deb` and `.rpm` packages, Windows installers and portable ZIPs, and macOS DMGs include updater metadata and checksums. Mobile and Microsoft Store/MSIX packages are not part of this release.
