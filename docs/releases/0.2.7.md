# Clovercut 0.2.7

## Modern CapCut draft import, multi-clip audio detach, ReaCut title presets, and range export

- **Modern CapCut Desktop Draft Decryption & Import:** Import modern CapCut Desktop projects (`draft_content.json`) directly into Clovercut. Resolves AES-256-GCM 12-split draft encryption automatically from both project folder selection and direct draft file selection. Timelines, media clips, text styles, speed adjustments, and supported transitions convert cleanly into an independent Clovercut project without modifying the original draft.
- **Atomic Multi-Clip Audio Detach & Reattach:** Detaching audio now works across multiple selected clips simultaneously. Audio tracks are created and synchronized across all selected video clips in a single atomic batch transaction with unified undo/redo. Reattaching audio cleanly restores audio streams to their parent video clips.
- **8 ReaCut Text Presets:** Eight production-ready title presets are bundled directly into the text library: Cinema, Classic, Chapter, Minimalist Editorial, Quote, Breaking News, Minimal Lower Third, and Neon Glow. Presets provide styled typography, letter tracking, shadows, and layout structures ready for drag-and-drop timeline placement.
- **Export Selected Time Range:** The export panel now supports targeting either the entire timeline or the selected clips / In-Out range. Selection duration and estimated file sizes update dynamically in real time. Available across all 25 supported locales.
- **Full-Range Color for Shapes and Titles (Issue #61):** Shapes, vector elements, and rendered title graphics now use the full color range (0–255), preserving pure whites and preventing crushed or clipped highlight levels.
- **Captions Editor Text Padding and Word Wrapping (Issue #63):** Fixed horizontal text truncation and boundary clipping in the subtitle and caption editor with responsive padding and accurate word wrapping.
- **3-Point Editing & Slip Tooling:** Insert and overwrite editing workflows from monitor in/out markers, plus slip clip operations that preserve synchronization across linked and detached audio.

## Downloads

Linux x86_64/ARM64: AppImage, deb and rpm. Windows x64/ARM64: installer and portable ZIP. macOS Apple Silicon/Intel: DMG. Downloads include SHA256SUMS and an updater manifest.

macOS packages are ad-hoc signed and are not Apple-notarized; follow the [first-launch instructions](https://github.com/tulcoturo/clovercut/blob/v0.2.7/docs/MACOS_INSTALLATION.md). Physical-device compatibility and performance depend on the machine. Mobile packages are outside this desktop release.
