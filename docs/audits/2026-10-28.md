## Confirmed gaps

### CI and distribution

- `linux-packaging.yml` runs on selected PRs or manual dispatch. `release.yml`
  calls `ci.yml` and `build-app.yml`, but does not require that regression workflow.
  Creating packages is not equivalent to running installer tests on the release SHA.
- `ci.yml` does not run the bundled connector's Node tests.
- Test reports/logs are retained only on failure. Preserve compact successful
  reports to compare timings and ignored coverage.
- Linux builds smoke-test AppImages in clean distributions. Add actual `.deb`
  and `.rpm` install/launch/upgrade/remove checks in disposable containers.
  Payload inspection does not exercise package-manager behaviour.
- Windows/macOS startup checks are valuable but do not replace interactive
  editing qualification on those systems.

### Desktop feedback and accessibility

- `studio.rs::enhance_readout` estimates frames using whole-media duration,
  while `start_enhance` requests the selected source span with margins. A short
  clip from a long recording can show an inflated estimate. Share span calculation,
  including retimed and already-enhanced clips.
- The shared `IconButton` in `ui/primitives/panel.slint` has keyboard activation
  and tooltip text, but no explicit accessible role, label or default action.
  Other controls already declare these. Audit this component and its callers,
  including the playhead split button: keyboard support alone does not establish
  screen-reader support.
- The screenshot driver does not establish pointer hit-testing, focus order,
  screen-reader behaviour, narrow-layout clipping or contrast. Review these
  interactively; this source audit does not claim unobserved visual defects.

### Maintainability and resources

- `studio.rs` is about 15,948 lines, combining policy, UI publication, job delivery
  and tests. Extract cohesive pure policies while fixing related behaviour;
  avoid a rewrite based solely on file length.
- Seven historical phase-3/4/5/6/7 files total 5,548 lines. Replace phase labels
  with behaviour names and document prerequisites and actual execution schedules.
- Build-profile comments retain historical machine-specific timings that do not
  represent the current UI on the 16 GiB development machine. Centralise guidance.
- Disk-cache growth, stale downloads, connector session expiry/reconnect and log
  retention need measured scenarios. This pass does not establish leaks,
  credential exposure or a currently broken external provider.
