## Validation

- Formatting, full workspace Clippy, strict locale/model inventories and documentation checks passed. Workspace execution passed 1,328 cases; gRPC Clippy and all 30 gRPC cases passed. Connector and Linux packaging regressions also passed.
- All six native desktop package jobs passed: Linux x86_64/ARM64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon. Linux checks exercised AppImage startup and native `.deb`/`.rpm` install, launch, reinstall and removal with application data preserved. Windows package and CPU compatibility gates passed.
- Both downloaded macOS DMGs passed independent static inspection: the application version is 0.2.1, CPU architectures match, every eager launch binary declares minimum 12.0, and no binary imports a `VTPixelRotationSession` symbol. The Intel bundle's separately guarded ONNX runtime retains minimum 13.4 and is not eagerly linked. Raw reports: [Apple Silicon](data/2026-10-30-release-021-macos-arm64.json), [Intel](data/2026-10-30-release-021-macos-x86_64.json).
- Twelve selected virtual desktop regressions passed for the feature source `67b3c892` in [combined CI](https://github.com/tulcoturo/clovercut/actions/runs/40894951139), including inline rename persistence/recents and poster invalidation. Version preparation changed only workspace versions and release notes. The release workflow does not rerun that optional desktop selection.

## Publication verification

The [verification record](data/2026-10-30-release-021.json) confirms the exact resolved tag, latest stable release, twelve nonempty desktop packages, updater manifest and release checksums. All GitHub asset digests agree with the published checksum file; downloaded metadata hashes, package sizes and manifest URLs agree. The independently inspected DMG hashes match the published assets. No mobile or MSIX package is included.

README, installation examples, site downloads and repository Arch metadata were updated after release verification. [Pages deployment](https://github.com/tulcoturo/clovercut/actions/runs/41035940372) succeeded; live HTML and JavaScript were fetched and confirmed to use 0.2.1 with cache key `20261030-021`.

Both Arch AppImage hashes match the release. [AUR publication](https://github.com/tulcoturo/clovercut/actions/runs/41035481672) explicitly skipped external publication because `AUR_SSH_KEY` is not configured. A successful workflow status is not evidence that the external AUR package was updated. Direct downloads and the installer's stale-AUR fallback remain available.

## Limits

Actual launch on Monterey remains unconfirmed because no macOS 12 test machine is available. Native checks ran on modern macOS runners. Physical audio, accessibility, live-provider journeys, the separate ten-minute drift measurement and cross-version native upgrades remain unqualified. Same-version Linux package lifecycle checks do not establish a 0.2.0-to-0.2.1 upgrade test.
