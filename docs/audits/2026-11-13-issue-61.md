# Issue 61: shapes and preview controls

Issue: https://github.com/tulcoturo/clovercut/issues/61

The shape inspector adapts Concat `0b1f125d`: editable figure, width/height,
corners, polygon/star settings, fill and gradient, outline and line heads, trim
and shadow. Shape updates use the existing echo/commit transaction and one-step
undo. Old `size` values deserialize as width and old arrows retain their heads.
The shape's own dimensions change under its side grips rather than stretching
its outline. The title cache version advances to discard old shape images.
The new painter retains Clovercut's fast PNG encoding and owned RGBA conversion.
The API's ClipPatch accepts the shape and rejects non-finite values as for other
editable properties; the MCP schema budget follows upstream `c009d037`.

Full-screen preview expands the clicked monitor seat and enters native window
fullscreen. F11 also toggles it; Esc exits, after dismissing any sheet above it.
Transport controls remain available. The prior native fullscreen state is
restored, and the dock tree is retained. Compact/wide layout swapping is held
while entering fullscreen; closing the project exits the temporary mode.

Shift temporarily holds the current hover preview. It does not disable playback
or repurpose Shift selection/edit shortcuts. Releasing it resumes preview;
native modifier and window-focus events clear the hold even if a text field
consumes the key or the compositor omits a release. The user's follow-up
authorized choosing the behavior appropriate for an editor rather than requiring
an exact undocumented CapCut shortcut.

New preferences stop the playhead at the content end by default. Existing saved
false values retain the user's prior setting; Settings > Playhead can still
allow navigation beyond the content for placing new footage. Empty timelines
remain at zero when end-bounded navigation is enabled.

Local project and text tests passed (246 project-library tests, the integration
suites, and 91 text tests including the imported painter cases). All actual
application Slint sources compile without compiling or launching the native GUI
locally. The existing remote editor journey adds colour commit/undo/redo,
temporary hover hold and seek-bound checks. Native validation and release
publication remain pending; this record is not a claim of physical desktop QA.
