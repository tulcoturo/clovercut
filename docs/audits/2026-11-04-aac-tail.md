# AAC mix tail

Selective adaptation of Concat `536a416d1118319982e96000d3d64a7c70ab9061`.

The AAC mix writer now drops packets beginning at or after the requested sample
count and shortens packet duration at the final boundary, before timestamp
rescaling. Negative priming timestamps and packets without timestamps remain
intact. The sample count uses the same rounding as the existing mix graph.
The existing PCM and Opus paths, cancellation and encoder selection are retained.

This deliberately does not adopt platform AAC selection: AudioToolbox and Media
Foundation availability and runtime opening require separate platform validation.
It also avoids applying AAC padding rules to Opus, whose discard metadata differs.

Validation on Linux with the local FFmpeg libraries: all 27 audio regression
tests passed. New packet cases cover priming, partial tail, padding-only packets,
exact end and absent timestamps. The existing WAV/M4A save journey now also
checks AAC stream duration within 1 ms of its 6007-sample mix, alongside existing
PCM sample, fade, gain and cancellation assertions. A millisecond tolerance
reflects container timing; this does not assert decoded AAC sample-count equality.

No Apple encoder was exercised, so the upstream-reported Apple padding failure
has not been reproduced locally. Full native CI remains a separate gate.
Strict `cargo clippy -p concat-media --all-targets -- -D warnings` also passed.

Follow-up qualification with the pinned Rust toolchain: the complete media
library suite passed (158 passed, 3 ignored). An additional six-second M4A
regression places an audible transient at exactly one second, verifies its
strongest decoded peak remains within two samples, and checks fractional
container duration within 1 ms. This exercises the linked Linux AAC encoder;
it still does not qualify AudioToolbox or Media Foundation.

Full run 41901083976 reached the selected desktop suite but failed its transport
clock journey: an opening seek was classified as a scrub and its permitted
nearest frame was asserted as exact before refinement. The test now permits
that intermediate nearest result; it still requires the correct paused frame
before playback, exact-request pixels, published-image equality, matching
running-clock frames and the existing timeout. This is a test synchronization
correction, not an AAC failure or a change to preview behavior. The branch is
rebased by merging the qualified caption/effect main before renewed native CI.
