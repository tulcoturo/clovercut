# Tracked facial accessories

Adds `concat.face-sunglasses` and `concat.face-dog`, in the Face catalogue category. The glasses follow the eyes; the dog accessory combines floppy ears with a muzzle and nose. Both are procedural GPU drawings, not static overlays at the frame centre.

The bundled MIT-licensed YuNet detector supplies five 2D landmarks for up to four faces. The pinned 232589-byte model is checked against its upstream SHA-256; attribution and full licence ship in the source tree. It uses the existing ONNX runtime, without an additional service, SDK, model download or image upload. Aspect-preserving source images are padded to its fixed 640-square input, then detections are returned in original source fractions.

The host analyses requested source ranges at 20 Hz through its existing single-flight, cancellation, epoch and crash-tripwire infrastructure. Silhouette masks and facial detections have independent request identities and cache directories. Applying two facial accessories shares one analysis. Explicit no-face records prevent repeated analysis. Playback interpolates spatially matched neighbouring detections, rejecting disappearance, large displacement and scale jumps rather than bridging a cut. No 3D mesh, mouth-expression recognition, identity recognition or full head-rotation reconstruction is claimed.

Versioned sidecars contain at most four validated five-point faces per source instant. Atomic writes prevent partial results. Inference never happens in the renderer. Preview and export resolve source-time geometry from the same sidecar and compose decoder crop/flip with compositor crop/flip/stabilization mapping. A 224-byte uniform shares the existing reveal bind group; the renderer retains four bind groups, bounded upload caches, scene-linear colour and straight-alpha composition. Without detections the shaders are no-ops.

Accessories belong to source clips and run in the source-decoration stage before ordinary image distortions. Existing project command guards and inspector stage boundaries apply. The effect inspector displays shared analysis progress. Thumbnail reference landmarks are annotated on a crop of the existing fictional-person source; no inference/download happens on hover. Native tests also detect the actual reference face and render genuine inferred landmarks for visual review.

Validation covers malformed detector outputs, real offline inference and a blank negative image, sidecar corruption/empty results, bounded interpolation and cuts, uniform layout/mapping, project source-only ownership, package default/min/max probes, GPU no-face/movement/background behavior, and native thumbnail/inferred landmark captures. Native and visual CI results must be reviewed before integration or a test package is offered.
