Set the mood

Find your next sound.

Browse music and sound effects from OpenGameArt, Freesound and YouTube Audio Library. Preview a track and check its licence before adding it.

Online libraries are optional and require setup. Some need an API key; YouTube uses the bundled local Audio API and Studio sign-in with Chrome, Chromium or Edge installed. See the setup guide
